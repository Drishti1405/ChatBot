> **Nova AI** is an advanced, production-grade conversational copilot and document intelligence workspace engineered with Vanilla JavaScript (ES6+), modern CSS Glassmorphism, Google Gemini 2.0, PDF.js document vectorization, and Web Audio/Speech APIs.

---

## 🚀 Key Highlights & Resume Talking Points

- **Aesthetic Neural Preloader & Session Reloader**: Multi-ring cybernetic preloader on launch with animated progress metrics, alongside an aesthetic "Neural Sweep" session reloader that clears context and refreshes persona state.
- **Multimodal PDF Document Intelligence**: Client-side document parser powered by PDF.js with real-time text extraction, document chip metadata, and contextual question-answering with zero backend latency.
- **Dual-Mode Experience (Studio Workspace & Floating Widget)**: Seamless transition between a ChatGPT/Perplexity-class full-screen desktop studio and a floating docked widget pill with animated pulse rings.
- **Synthesized Web Audio Engine**: Zero-asset audio interaction suite powered by real-time Web Audio API oscillators for message transmission, reception, and session reload chimes.
- **Voice Capabilities**: Bi-directional voice interaction with Web Speech API speech-to-text dictation (dynamic equalizer waveform) and Text-to-Speech (TTS) audio playback.
- **Markdown & Code Engine**: High-performance Markdown rendering with Marked.js and Highlight.js syntax highlighting, featuring custom code container headers, language badges, and one-click copy feedback.
- **Persona Cognitive Pipeline**: Dynamic cognitive system prompts for **Full-Stack Architect**, **Resume & Career Coach**, **Research Analyst**, and **General Copilot**.
- **Interactive Offline Showcase + Live Gemini API**: Dual-mode execution engine providing intelligent offline streaming demo responses for recruiters/portfolio reviewers, plus live Google Gemini API connectivity with local key persistence.

## ⚡ Quick Start

To launch the project locally:

```bash
# Navigate to project directory
cd chatbot

# Start the backend server (serves frontend & AI proxy)
python3 backend/server.py
```

Then open your browser at **[http://localhost:3000](http://localhost:3000)**.
