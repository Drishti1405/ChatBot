# 🎨 Nova AI — Frontend Client

The frontend is a luxury, responsive web interface built with modern vanilla web standards (HTML5, CSS3, ES6+).

## Files
- `index.html`: Semantic HTML5 layout, Google Fonts, icons, modal dialogs, and audio hooks.
- `style.css`: Glassmorphic design system, CSS variables, dark/light themes, animations, and mobile responsive media queries.
- `script.js`: Reactive state management (`APP_STATE`), audio synthesizer, PDF text extraction (PDF.js), speech-to-text / text-to-speech (Web Speech API), Markdown & code highlight rendering (Marked.js, Highlight.js), and streaming AI chat responses.

## Key Frontend Features
- **Zero Framework Bloat**: Pure Vanilla ES6+ and CSS3 for lightning-fast loads.
- **Glassmorphism UI**: Backdrop blur, subtle borders, gradient accents, smooth hover transitions.
- **Dual Display Modes**: Toggle between full-screen Studio mode and compact floating Widget mode.
- **Client-Side PDF Parsing**: Parses and extracts text from uploaded PDF documents locally using PDF.js.
- **Audio Synthesizer Engine**: Generates real-time sound effects via the Web Audio API without needing external MP3 audio files.
- **Voice Dictation & Read-Aloud**: Full speech-to-text voice input and speech synthesis read-aloud.
- **Export to Markdown**: One-click download of the complete chat history as formatted Markdown.
